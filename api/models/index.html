    Models¶

    All models are importable directly from pyawe:

    from pyawe import Workflow, Task, Job, Status, TaskType

    Enumerations¶

    pyawe.models.Status ¶

    Bases: str, Enum

    Lifecycle status shared by workflows, tasks, and jobs.

    CANCELLED, REWORKED, and FAILED are task-only and system-managed: CANCELLED is set automatically by the propagator when a task is on a rejected decision branch; REWORKED is set only by the manual rework trigger (POST /tasks/{id}/rework); FAILED is set only when a checkpoint's required check is marked failed. None of these should be set via update_task.

    pyawe.models.ScheduleStatus ¶

    Bases: str, Enum

    Schedule health indicator shared by workflows, tasks, and jobs.

    Data type carried by a task or work item port.

    SECRET is valid only on work item port specs: it declares the slot, but the value itself is set per task instance via TaskSecretsClient after instantiation.
