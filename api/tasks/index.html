    Update a task; only supplied fields are changed.

    assigned_to, decision_input_port, effort, due_time, branch_name, and port_namespace are tri-state fields:

    • Omitted (default): field is left unchanged.
    • None: clears the current value.
    • A value: sets the field.

    Parameters:

    Name Type Description Default
    task_id UUID | str

    UUID of the task to update.

    		 required
    name str | None

    New name.

    		 None
    is_template bool | None

    Template flag.

    		 None
    description str | None

    New description.

    		 None
    status Status | str | None

    New status. Completed/cancelled tasks cannot be transitioned. Setting to "In Progress" stamps start_time; setting to "Complete" stamps end_time.

    		 None
    schedule_status ScheduleStatus | str | None

    New schedule status.

    		 None
    rework_task_id UUID | str | None

    Rework back-link.

    		 None
    is_start bool | None

    Start task flag.

    		 None
    is_end bool | None

    End task flag.

    		 None
    task_type TaskType | str | None

    Task type string.

    		 None
    assigned_to Any

    User ID string, None to clear, or omit to leave unchanged.

    		 _UNSET
    decision_input_port Any

    Input port name for auto-decide, None to clear, or omit to leave unchanged.

    		 _UNSET
    is_locked bool | None

    Lock or unlock structural edits (requires owner/leader/admin).

    Canvas X position from the workflow editor.

    		 None

    		 _UNSET
    branch_name Any

    		 _UNSET
    port_namespace Any

    request_rework ¶

    request_rework(task_id: UUID | str) -> Task

    Manually trigger a rework of task_id.

    Spawns a fresh clone of the subgraph between the task's configured rework_task_id and the task itself, rewires the clone chain in place of the original, and marks the original task "Reworked". The original target/intermediate tasks are never touched.

    Parameters:

    Name Type Description Default
    task_id UUID | str

    UUID of the task that judged rework was needed (the "source" task; must already have rework_task_id set).

    		 required

    Returns:

    Type Description
    Task

    The reworked (now "Reworked"-status) :class:~pyawe.models.Task.

    Raises:

    Type Description
    AweNotFoundError

    If the task does not exist.
    AweValidationError

    If the task has no rework_task_id configured.
    AweAuthError

    If not authenticated.
